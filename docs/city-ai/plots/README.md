## Plot Naming Convention

Files are named by their trigger or purpose:
- `new-arrival.md` - Triggered by new player entry
- `pipe-repair.md` - Infrastructure repair template
- `security-incident.md` - Response to threats

## Using These Templates

These are reference implementations. Adapt to circumstances:
- Locations change based on where events occur
- NPC names and traits should vary
- Dialogue can be adjusted while maintaining tone
- Timelines are minimums, not absolutes
